# Contributing

Thanks for helping improve these samples.

## What belongs here

Framework examples that run against AI Server's OpenAI-compatible API and that a developer can read
in one sitting. A new framework earns its place if it is widely used and works against the OpenAI-compatible API.

## Ground rules

- **No secrets.** No API keys or hostnames in code.
- **Run it before you send it.** Say in your PR which model you used and paste the [PASS] line.
- **Cap every loop** and keep the token check so a pass means a real tool round trip.
- Configuration comes from `AISERVER_BASE_URL` / `AISERVER_API_KEY` / `AISERVER_MODEL`.
